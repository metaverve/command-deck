Ops Planning

Work management for boards, groups and tasks, with table and Kanban views, comments, search and filters, dashboards and one status-based automation. Built from the Metaverve Work app (version 0.2.0).

Open Ops Planning Sign in
Opens in a new tab. The app blocks being shown inside other sites for security, and it signs in with the owner's GitHub account only.

What it does

  • Create and rename boards, create groups, create, edit, regroup and archive tasks
  • Task title, description, status, priority, assignee and due date
  • Table and Kanban views, with drag and drop and keyboard status controls
  • Task comments and activity history, combined filters, workspace search and My Work
  • Counts, completion and workload, with drill-through
  • Optional automation, off by default: move a task to a chosen group when it's marked Done

Good to know

  • Owner-only access, with no invites or live collaboration yet
  • Assignees, comments and automations are records only. It sends no notifications or messages.
  • Archived tasks are kept, but there's no restore screen yet
  • No custom columns, subitems, dependencies, timeline or attachments
  • The activity log shows the latest 300 events
